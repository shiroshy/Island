# Island
<img width="1919" height="1079" alt="image" src="https://github.com/user-attachments/assets/8631a306-d3c8-4811-a408-1d84b7ecdde0" />

Требуется Windows 10 x64

1. Скачайте `Island-0.20.1-win-x64.zip` из [Releases](https://github.com/shiroshy/Island/releases/latest).
2. Распакуйте архив в постоянную папку
3. Запустите `Island.Start.exe` без прав администратора
4. При необходимости включите автозапуск в настройках

Для отключения запустите `Stop-Island.cmd`.
Функции рабочего стола и файлового менеджера находятся в разработке и могут работать не стабильно.
