# Island
<img width="1919" height="1079" alt="image" src="https://github.com/user-attachments/assets/8631a306-d3c8-4811-a408-1d84b7ecdde0" />

Требуется Windows 10/11 x64. Программа работает вместе с Explorer.

1. Скачайте `Island-Setup-0.20.3-Win10-11-x64-InternalSettings.exe` из [Releases](https://github.com/shiroshy/Island/releases).
2. Запустите установщик и подтвердите запрос прав администратора.
3. Откройте Island из меню «Пуск».

При обновлении сохраняются пользовательские настройки. В папке установки есть `Uninstall-Island.cmd` для удаления программы вместе со службой и `Remove-Island-Service.cmd` для удаления только службы. Пользовательский профиль сохраняется.

Сборка: `powershell -NoProfile -ExecutionPolicy Bypass -File package.ps1`. Готовый установщик находится в `dist/`.
