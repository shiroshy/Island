# Island

Требуется Windows 10 x64.

1. Скачайте `Island-0.20.1-win-x64.zip` из [Releases](https://github.com/shiroshy/Island/releases/latest).
2. Распакуйте архив в постоянную папку.
3. Запустите `Island.Start.exe` без прав администратора.
4. При необходимости включите автозапуск в настройках Island.

Для отключения запустите `Stop-Island.cmd`.
