Добавлено подключение Wallpaper Engine для большого рабочего стола: выбор текущих обоев или проекта, автоматический поиск установки и сохранение выбора по мониторам.

Исправления:
- Ускорена обработка MP4; просроченные кадры не копируются для показа.
- Исправлены получение текущих обоев Wallpaper Engine и выбор монитора.
- Панель оформления больше не пропускает нажатия к виджетам под ней.
- Окно скрытых значков трея расширяется при добавлении значков и уменьшается после их удаления.
- Улучшено определение окон приложений с отдельным окном содержимого.
- Исправлено возвращение рабочего стола после полноэкранного приложения: окно Wallpaper Engine сохраняется и сворачивается без повторной загрузки проекта. Неизменные уведомления экрана больше не пересоздают графику стола; отрисовка возобновляется сразу после обнаружения открытого стола.

Для Wallpaper Engine требуется установленная программа. Используется отдельное окно обоев через её командный интерфейс. Проверен видеопроект; совместимость всех сцен и веб-обоев не гарантируется. Интерактивность обоев и синхронизация пресетов не поддерживаются; звук определяется настройками Wallpaper Engine.

Для обновления закройте Island через Stop-Island.cmd и замените файлы в папке программы. Пользовательские настройки хранятся отдельно и сохраняются. Архив не содержит личных данных, настроек входа в Windows и экспериментального системного хоста.
